Hunch is a self-play-native programming language for RL environments.

Quickstart

Install it, solve Kuhn poker, ask why it made each move, then take a seat against it. Needs python3 and a C compiler.

$ pip install git+https://github.com/knownquantity/Hunch
$ hunch train kuhn
$ hunch why kuhn
$ hunch play kuhn

One file in, a strategy out

This is all of Kuhn poker, the smallest game in which bluffing is correct. Each highlighted hunch is a decision left blank: who decides, what they are shown, and what they can do. Two names in one file are two agents that learn against each other.

That is the textbook answer. The game is worth −1/18 to the first player, and alice bluffs with the lowest card 19% of the time. Nobody wrote “bluff” anywhere.

Games up to about two million positions are solved exactly, like this one. Connect Four, at 4.5 trillion, is too big for that, so train gives it a policy that searches at each move, and teaches it by having it play itself for ten minutes. On a 5×4 board, where perfect play is known, the result drew 100 of 100 games against it in each seat. Full Connect Four has not been measured against perfect play. Every limit is written down.
