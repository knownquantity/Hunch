Studio

The Studio is a page that replays four of the shipped worlds, the dungeon, the market, the duel and the cache, untrained beside trained, and retrains them while you watch. It needs the runtime, so it runs on your machine from a checkout, not in the browser:

git clone https://github.com/knownquantity/Hunch
cd Hunch
./bin/hunch studio

The trained policies for those four worlds come with the checkout. The Studio does not show Connect Four or the search yet.
